## Research to implementation

[HIG Charts](https://developer.apple.com/design/human-interface-guidelines/charts.md) was read in Markdown in this iteration. Istithmar uses a labeled zero-based comparison scale, a selected cost horizon, explicit units, numerical alternatives to the plot, and predictable period controls. Its horizon is a planning input, not historic performance. Equal quarter-horizon samples use actual relative x positions. Exact minor-unit scaling avoids floating-point overflow for large values. Activity-list matches precede cost order and are not called license eligibility.

Expo 58 file-system and sharing docs and the React Native Animated documentation were consulted before changing export and transition behavior. No dependency or Apple-branded asset was added. The new plot uses existing react-native-svg and React Native controls. Reduced motion stops the crossfade while values remain available immediately.

The earlier HIG/WWDC/Design Awards study remains in `project/APPLE_DESIGN_RESEARCH.md`. The six user-requested award dimensions are internal review prompts, not awarded scores or a prediction. No portfolio acceptance is granted by this study.
