# Mandatory 25-app design matrix

The user specification is preserved in [USER_SPECIFICATION.md](USER_SPECIFICATION.md); [matrix.json](matrix.json) is its structured product matrix. Palette and Latin/Arabic typography directions now drive the native assets and UI. Selected text/action tones are derived for contrast while the requested palettes remain recorded.

Each app has five route surfaces: its home, case, public research, history and a named domain workbench. Workbenches expose existing on-device tools and entered data rather than fake service integrations. The shared route shell does not establish 25 independent UX architectures. Final cross-product distinction remains unaccepted.

[Delivery ledger](delivery-ledger.json) records every implemented scope, missing integration and all five unaccepted gates. The 125 route surfaces are a review baseline; they are not 125 independently accepted designs. Existing 25 historical synthetic RAG milestones remain intact and separate.

[Palette contrast](../evidence/matrix-palette-contrast.json) · [Arabic font licenses and coverage](../evidence/arabic-typeface-inventory.json) · [Actual host RTL shaping](../evidence/arabic-shaping-checks.json). Host rendering does not prove native shaping, screen-reader performance or large-text acceptance.

Live restaurant discovery, verified local fasting schedules, camera material recognition, bank/meter integrations, official submissions and food-bank coordination remain unavailable where specified in the ledger. No such capabilities are inferred from attractive screens.
