# Tawteen AI — independent creative direction

Status: authored direction; implementation evidence and acceptance tracked separately.

## 1. Brand philosophy

People before compliance percentages

## 2. Emotional identity

Respect and accountable stewardship

## 3. Logo and wordmark

Two unequal solid forms held by a shared baseline; split stacked workforce wordmark

## 4. Typography

manrope for the wordmark and key headlines. Wordmark 29 pt, tracking 0.6; headline 39 pt with 1.12 leading ratio. Body 17/26 using the platform reading face. Preserve system scaling, multiline content and readable fallback; never shrink body text to fit.

## 5. Color system

Paper #F3F5E7, ink #1D382D, accent #376844, secondary surface #FFFFFF. Status is also expressed in words, not color alone.

## 6. Visual language

workforce composition, individual original artwork, and the mark geometry described above. Decorative imagery never stands in for verified output.

## 7. Information architecture

Workforce roster → supplied target basis → aggregate result → policy context

## 8. Interaction philosophy

Inspect headcounts and basis before interpreting the percentage

## 9. Motion identity

Aggregation resolves from actual rows, with no decorative growth animation This describes the product target; current implementation and device acceptance must be checked separately.

## 10. Agentic AI experience

Computed target gaps are tied to the supplied workforce. Policy context is not an authenticated payroll integration.

## 11. Signature experience

One employee correction changes the recomputed aggregate

## 12. Platform adaptation

iOS: safe areas, system text scaling, native stack back and accessible modal dismissal. Android: system back, keyboard insets, 48 dp actions and no dependence on an iOS-only gesture. Both: reduced motion and screen-reader labels. Physical-device verification remains open.

## 13. Differentiation evidence

workforce brand composition; Workforce roster → supplied target basis → aggregate result → policy context. Compare all four corresponding screens against the portfolio, not just the hero image. Similarity is a review trigger, never proof of creative success.

## 14. Implementation feasibility

Bundled licensed font, independent vector identity, static route content and actual schema-bound inputs. Reuse data validation and authentication without forcing this content into a shared dashboard. Functional boundary: Policy context is not an authenticated payroll integration.
