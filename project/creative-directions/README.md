# Independent creative directions

Each direction defines fourteen product decisions. Direction is distinct from implementation and acceptance. The current iteration implements the individual marks, wordmarks, native identity assets, heading proportions, domain case interactions and public-research compositions. Motion philosophies are targets; shared navigation, private-history presentation, actual-device verification and final visual acceptance still require review.
