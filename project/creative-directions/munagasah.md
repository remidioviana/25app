# Munagasah AI — independent creative direction

Status: aligned to the mandatory user matrix; implementation scope and native acceptance remain separate.

## 1. Brand philosophy

A bid is an evidence argument

## 2. Emotional identity

Readiness, focus and disciplined momentum

## 3. Logo and wordmark

Bold condensed lettering; distinctive folded-bid emblem. Archivo Narrow with Tajawal.

## 4. Typography

Archivo Narrow for Latin branding and Tajawal for Arabic input. Both are bundled under retained OFL notices. Coverage and shaping evidence is separate from native screen-reader and font-scaling acceptance.

## 5. Color system

Graphite `#282A2F`, amber `#FFBE59`, porcelain `#F4F2EC`. Technical blueprints and procurement-document graphics. Accessible text/action tones are recorded separately; the requested signal colors remain the art-direction basis.

## 6. Visual language

blueprint composition, individual original artwork, and the mark geometry described above. Decorative imagery never stands in for verified output.

## 7. Information architecture

Tender cover → requirement matrix → capability evidence → submission clock

## 8. Interaction philosophy

Move from a requirement to supporting capability before drafting prose

## 9. Motion identity

Crisp sectional reveals follow evidence acquisition, not fictitious completion percentages This describes the product target; current implementation and device acceptance must be checked separately.

## 10. Agentic AI experience

**Tender Strategist:** discovers published opportunities, checks qualification criteria, tracks deadlines, and drafts bid-preparation tasks. This is the target specification. Implemented scope and unavailable integrations are listed in the design-matrix delivery ledger.

## 11. Signature experience

The procurement channel stays separate from an actual tender pack

## 12. Platform adaptation

iOS: safe areas, system text scaling, native stack back and accessible modal dismissal. Android: system back, keyboard insets, 48 dp actions and no dependence on an iOS-only gesture. Both: reduced motion and screen-reader labels. Physical-device verification remains open.

## 13. Differentiation evidence

bidroom brand composition; Tender cover → requirement matrix → capability evidence → submission clock. Compare all four corresponding screens against the portfolio, not just the hero image. Similarity is a review trigger, never proof of creative success.

## 14. Implementation feasibility

Bundled licensed font, independent vector identity, static route content and actual schema-bound inputs. Reuse data validation and authentication without forcing this content into a shared dashboard. Functional boundary: A public eSupply page is not a tender and cannot establish bid fit.
