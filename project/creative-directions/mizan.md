# Mizan AI — independent creative direction

Status: authored direction; implementation evidence and acceptance tracked separately.

## 1. Brand philosophy

Values require a clear ledger

## 2. Emotional identity

Stewardship and transparent judgment

## 3. Logo and wordmark

A solid offset counterweight balanced by an open ledger line; emphatic financial monogram

## 4. Typography

fraunces for the wordmark and key headlines. Wordmark 43 pt, tracking -1.1; headline 47 pt with 1.12 leading ratio. Body 17/27 using the platform reading face. Preserve system scaling, multiline content and readable fallback; never shrink body text to fit.

## 5. Color system

Paper #08271F, ink #F2F1DA, accent #BDE7A0, secondary surface #272541. Status is also expressed in words, not color alone.

## 6. Visual language

balance composition, individual original artwork, and the mark geometry described above. Decorative imagery never stands in for verified output.

## 7. Information architecture

Financial position → budgets panes → verified transactions → values context

## 8. Interaction philosophy

Separate recorded arithmetic from the interpretation of Islamic-finance guidance

## 9. Motion identity

Numeric changes resolve directly; no wealth-growth celebration This describes the product target; current implementation and device acceptance must be checked separately.

## 10. Agentic AI experience

The agent reconciles supplied records before offering source-linked context. No bank access, investment promise or religious certification.

## 11. Signature experience

A disputed transaction can be excluded without changing its original record

## 12. Platform adaptation

iOS: safe areas, system text scaling, native stack back and accessible modal dismissal. Android: system back, keyboard insets, 48 dp actions and no dependence on an iOS-only gesture. Both: reduced motion and screen-reader labels. Physical-device verification remains open.

## 13. Differentiation evidence

counterweight brand composition; Financial position → budgets panes → verified transactions → values context. Compare all four corresponding screens against the portfolio, not just the hero image. Similarity is a review trigger, never proof of creative success.

## 14. Implementation feasibility

Bundled licensed font, independent vector identity, static route content and actual schema-bound inputs. Reuse data validation and authentication without forcing this content into a shared dashboard. Functional boundary: No bank access, investment promise or religious certification.
