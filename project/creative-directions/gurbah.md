# Gurbah AI — independent creative direction

Status: authored direction; implementation evidence and acceptance tracked separately.

## 1. Brand philosophy

A move is a dependency map

## 2. Emotional identity

Belonging through orientation

## 3. Logo and wordmark

A stepping route that becomes an open arrival arch; tall map-like relocation signature

## 4. Typography

urbanist for the wordmark and key headlines. Wordmark 35 pt, tracking -1.2; headline 43 pt with 1.06 leading ratio. Body 17/26 using the platform reading face. Preserve system scaling, multiline content and readable fallback; never shrink body text to fit.

## 5. Color system

Paper #EDF6F2, ink #163E40, accent #177C7A, secondary surface #FFFFFF. Status is also expressed in words, not color alone.

## 6. Visual language

journey composition, individual original artwork, and the mark geometry described above. Decorative imagery never stands in for verified output.

## 7. Information architecture

Before-arrival map → dependency list → service context → settled tasks

## 8. Interaction philosophy

Follow prerequisites while retaining the option to explore ahead

## 9. Motion identity

Progressive path reveals reflect recorded dependencies only This describes the product target; current implementation and device acceptance must be checked separately.

## 10. Agentic AI experience

The agent orders supplied relocation tasks and highlights blockers. No invented immigration status or external service completion.

## 11. Signature experience

A dependent task points back to what must happen first

## 12. Platform adaptation

iOS: safe areas, system text scaling, native stack back and accessible modal dismissal. Android: system back, keyboard insets, 48 dp actions and no dependence on an iOS-only gesture. Both: reduced motion and screen-reader labels. Physical-device verification remains open.

## 13. Differentiation evidence

atlas brand composition; Before-arrival map → dependency list → service context → settled tasks. Compare all four corresponding screens against the portfolio, not just the hero image. Similarity is a review trigger, never proof of creative success.

## 14. Implementation feasibility

Bundled licensed font, independent vector identity, static route content and actual schema-bound inputs. Reuse data validation and authentication without forcing this content into a shared dashboard. Functional boundary: No invented immigration status or external service completion.
