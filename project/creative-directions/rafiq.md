# Rafiq — independent creative direction

Status: aligned to the mandatory user matrix; implementation scope and native acceptance remain separate.

## 1. Brand philosophy

Make room for what matters

## 2. Emotional identity

Clarity and everyday companionship

## 3. Logo and wordmark

Warm, organic wordmark; original continuous-path symbol. Quicksand with Noto Kufi Arabic.

## 4. Typography

Quicksand for Latin branding and Noto Kufi Arabic for Arabic input. Both are bundled under retained OFL notices. Coverage and shaping evidence is separate from native screen-reader and font-scaling acceptance.

## 5. Color system

Soft violet `#6D5B98`, warm white `#F9EEE8`, peach `#F4A89D`. Human-centered illustrations and gentle contextual photography. Accessible text/action tones are recorded separately; the requested signal colors remain the art-direction basis.

## 6. Visual language

orbit composition, individual original artwork, and the mark geometry described above. Decorative imagery never stands in for verified output.

## 7. Information architecture

Device-time dial → available day → commitments timeline → task placement

## 8. Interaction philosophy

See actual device time and arrange tasks within supplied boundaries

## 9. Motion identity

Clock updates are quiet; scheduling changes emphasize displacement This describes the product target; current implementation and device acceptance must be checked separately.

## 10. Agentic AI experience

**Daily Companion Agent:** organizes explicitly provided goals and available context, prepares useful next steps, and supports authorized personal workflows. This is the target specification. Implemented scope and unavailable integrations are listed in the design-matrix delivery ledger.

## 11. Signature experience

A genuine open interval is visible without inventing calendar access

## 12. Platform adaptation

iOS: safe areas, system text scaling, native stack back and accessible modal dismissal. Android: system back, keyboard insets, 48 dp actions and no dependence on an iOS-only gesture. Both: reduced motion and screen-reader labels. Physical-device verification remains open.

## 13. Differentiation evidence

orbit brand composition; Device-time dial → available day → commitments timeline → task placement. Compare all four corresponding screens against the portfolio, not just the hero image. Similarity is a review trigger, never proof of creative success.

## 14. Implementation feasibility

Bundled licensed font, independent vector identity, static route content and actual schema-bound inputs. Reuse data validation and authentication without forcing this content into a shared dashboard. Functional boundary: Device time is not a connected calendar or booked appointment.
