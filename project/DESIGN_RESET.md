# Independent product experience reset

The previous gallery exposed a repeated home template. The current reset replaces that home with 25 domain-specific compositions, distinct task language, typography treatments and visual signatures. Official-source information is visible before any workspace connection. It is not presented as AI analysis unless actual model output exists.

Twenty-five official reads were performed for the startup source excerpts. Each excerpt is matched against normalized source text, dated and fingerprinted in `evidence/ui-official-briefs.json`. Connected workspaces automatically refresh the app's selected official source. A changed or unavailable source cannot silently acquire a fresh timestamp.

A bounded public-intelligence workflow is being added separately. It uses actual protected model calls and source citations; no private customer data or synthetic customer example is used. Its results must be archived before being shown as AI analysis. Quota stops the batch. A captured-source fallback is explicitly labeled and retains its original date.

This checkpoint is not final originality or device acceptance. Navigation, per-screen interactions, original individual artwork, motion accessibility and the cross-app audit remain in progress. Physical iOS/Android workflow acceptance and deployment remain unverified. The existing 25 synthetic RAG milestones are preserved.
